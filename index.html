1. Manual: Publicar en GitHub Pages (HTTPS)

  1. Crear repositorio: En GitHub, crea un repositorio público (ej. manual-csharp).
  2. Subir archivos: Sube tu index.html y styles.css.
  3. Activar Pages: Ve a Settings > Pages.
  4. Desplegar: En Source, elige la rama main / root y guarda.
  5. URL Segura: Marca la casilla "Enforce HTTPS" para obtener el acceso seguro.

2. Encapsulamiento en C#

Es ocultar los datos internos de un objeto y permitir su acceso solo mediante métodos o propiedades autorizadas.

¿Para qué sirve?

  • Protege la integridad de los datos evitando cambios indebidos.
  • Oculta la complejidad interna de la clase.

3. Modificadores de Acceso (C# v5)

a) public

Accesible desde cualquier parte del programa.

public class Usuario {
    public string Nombre;
}

b) private

Solo accesible dentro de la misma clase. Es la base del encapsulamiento.

public class Cuenta {
    private double saldo;
    public void Depositar(double monto) { saldo += monto; }
}

c) protected

Accesible dentro de su clase y en clases que la hereden (hijas).

public class Vehiculo {
    protected string chasis;
}
public class Auto : Vehiculo {
    public void SetChasis(string c) { chasis = c; }
}

d) internal

Accesible solo dentro del mismo proyecto o ensamblado (DLL).

internal class Config {
    internal static string Ruta = "C:/app";
}
